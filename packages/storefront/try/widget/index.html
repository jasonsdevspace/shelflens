ShelfLens On a store's page
Maple Street Home's own banner, stacked over everything

Maple Street Home

A made-up store's own page, with styles that reach every list item, button and input, a banner over everything, a box that clips what it holds, and a React of its own. The search box below is embedded the way a store would embed it, and it searches the file of products you loaded, in this browser.

  • Free delivery on orders over $50, in this store's own list style.
  • The search box's list does not look like this.

All a store adds to its page

<div id="shelflens-search"></div>
<script type="module">
    import { mountShelfLens } from 'https://your-store.example/widget.js';
    mountShelfLens(document.getElementById('shelflens-search'), {
        apiUrl: 'https://your-store.example/graphql',
        storeUrl: 'https://your-store.example/',
    });
</script>

A real store points the box at its own search API, over its own catalog. This page points it at the file you loaded instead, which never leaves your browser, so it can only run on this site, where that file is kept.
