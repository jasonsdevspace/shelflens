Maple Street Home's own banner, stacked over everything

Maple Street Home

Maple Street Home is a made-up store, and this is its own page. Its styles reach every list item, button and input. A banner sits over everything, a box clips what it holds, and the page runs a React of its own. The ShelfLens search box is embedded here the way a real store would embed it, and it searches the file of products you loaded. Type a few letters from one of your products and watch the list. It keeps its own look and opens over the banner and out of the clipped box.

  • Free delivery on orders over $50. This is the store's own list style.
  • The suggestion list in the search box does not look like this.

What a store adds to its page

<div id="shelflens-search"></div>
<script type="module">
    import { mountShelfLens } from 'https://your-store.example/widget.js';
    mountShelfLens(document.getElementById('shelflens-search'), {
        apiUrl: 'https://your-store.example/graphql',
        storeUrl: 'https://your-store.example/',
    });
</script>

A real store points the box at its own search API and its own catalog. This page points it at the file you loaded instead. That file never leaves your browser. It is kept in this site's storage, so only a page on this site can search it, and no other site can reach it.
